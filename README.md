# Chronograph

Private repository scaffold for Chronograph.

Chronograph is intended as a context graph and task extraction layer for turning fragmented work signals into structured, source-grounded work state.

## Initial scope

- Context graph for people, projects, meetings, threads, documents, tasks, deadlines, owners, and decisions
- Task extraction from messy work inputs
- Source-grounded memory and traceability
- Continuity tracking across changing work state
- Proactive surfacing of open loops, blockers, and review-needed items
